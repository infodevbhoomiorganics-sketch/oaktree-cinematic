# Oaktree Homestay Website

## Overview
Build a polished nine-page boutique homestay website using only the ten supplied Oaktree photographs. The visual direction will be cinematic and editorial: forest green, warm cream, wood brown, restrained gold, large photography, refined serif headings, and subtle motion.

## Pages and structure
- Shared sticky transparent header, elegant mobile menu, booking links, floating WhatsApp contact, and dark earthy footer.
- Home: full-screen mountain hero, property introduction, and an image-led “Why Oaktree” story.
- Stay: large room photography, truthful descriptions limited to visible and confirmed details, and enquiry actions.
- About: family-run hospitality story with editorial photo layouts.
- Dining: home-cooked food, Himachali influence, local ingredients where applicable, restaurant, kitchen, and room service.
- Amenities: confirmed facilities presented with restrained icons and supporting photography.
- Experiences: orchard walks, mountain mornings, village atmosphere, Kumarsain, and nearby Narkanda.
- Gallery: asymmetric masonry photography with keyboard-accessible fullscreen lightbox.
- Location: exact address, supplied Google Maps embed, directions, call, and booking actions.
- Contact: prominent phone and WhatsApp booking options with the supplied pre-filled message.

## Photography
- Upload the ten supplied images through the project asset flow and import each image directly in the site.
- Use no stock, generated, placeholder, base64, or JSON image arrays.
- Preserve aspect ratios and assign descriptive alternative text throughout.

## Design and interaction
- Establish semantic design tokens for the natural palette, typography, shadows, and spacing.
- Use photo-led layouts rather than repetitive cards.
- Add restrained reveal motion, image zoom, page transitions, and lightweight parallax with reduced-motion support.
- Verify desktop and mobile layouts, menu behavior, links, gallery lightbox, and map rendering.

## Search and sharing
- Add unique titles, descriptions, Open Graph fields, canonical paths, and headings for all nine pages.
- Add Hotel and LocalBusiness structured data using only supplied facts.
- Maintain crawler access and add a sitemap once a public site URL exists; no public domain is currently available, so a new sitemap URL cannot yet be safely created.
